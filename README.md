# Awesome Cultural Color Resources

> Curated resources for culturally grounded color palettes, design tokens, Figma variables, Tailwind colors, and accessible color systems.

## Cultural Color Atlases

- [Chinese Color Atlas](https://chinesecoloratlas.com) - Chinese traditional color atlas with 567 colors, source notes, palettes, CSS/Tailwind snippets, Figma resources, Procreate samples, and AI prompt workflows.
- [Chinese Color Atlas Free Samples](https://github.com/chroma-cathy/chinese-color-atlas) - Free CSS variables, Tailwind tokens, Figma sample JSON, Procreate swatches, and AI prompt samples from Chinese Color Atlas by Chroma Cathay.
- [Nippon Colors](https://nipponcolors.com/) - Japanese traditional color names with a clean interactive palette interface.
- [Zhongguose](http://zhongguose.com/) - Widely referenced Chinese traditional color browsing site.
- [日本の伝統色](https://www.colordic.org/w/) - Japanese traditional color dictionary with named swatches and hex values.
- [Color Lisa](https://colorlisa.com/) - Color palettes inspired by famous artists and artworks.

## Design Tokens and Color Systems

- [Design Tokens Community Group](https://www.w3.org/community/design-tokens/) - W3C community group for design token standards and interoperability.
- [Design Tokens Format Module](https://tr.designtokens.org/format/) - Technical specification for design token file formats.
- [Style Dictionary](https://amzn.github.io/style-dictionary/) - Build system for transforming design tokens across platforms.
- [Tokens Studio for Figma](https://tokens.studio/) - Token workflow for Figma and design systems.
- [Awesome Design Tokens](https://github.com/sturobson/Awesome-Design-Tokens) - Curated resources about design tokens.
- [Primer Primitives](https://primer.style/primitives/) - GitHub's design token primitives and color foundations.

## Figma Variables and Design Handoff

- [Chinese Color Atlas Figma Sample](https://www.figma.com/community/file/1637863774550903181) - Duplicateable Figma Variables starter file for Chinese traditional colors with Guochao, Song-inspired, and Dunhuang palette modes.
- [Figma Variables](https://help.figma.com/hc/en-us/articles/15339657135383-Guide-to-variables-in-Figma) - Official Figma guide to variables for reusable design decisions.
- [Figma Tokens / Tokens Studio](https://www.figma.com/community/plugin/843461159747178978/tokens-studio-for-figma) - Figma plugin for managing and exporting design tokens.
- [Design Tokens Plugin](https://github.com/lukasoppermann/design-tokens) - Figma plugin to export design tokens to JSON.
- [Figma Export](https://github.com/RedMadRobot/figma-export) - Command-line utility to export colors, typography, icons, and images from Figma.

## Research and Reference

- [Interaction of Color](https://yalebooks.yale.edu/book/9780300179354/interaction-of-color/) - Josef Albers' classic work on color perception.
- [Munsell Color System](https://munsell.com/about-munsell-color/) - Reference system for hue, value, and chroma.
- [Oklab Color Space](https://bottosson.github.io/posts/oklab/) - Perceptual color space for modern color tooling.
- [Color and Culture](https://www.thamesandhudsonusa.com/books/color-and-culture-practice-and-meaning-from-antiquity-to-abstraction-softcover) - Reference book on color practices and meanings across cultures.
- [Wikisource Chinese](https://zh.wikisource.org/) - Public-domain Chinese source texts useful for historical color-name verification.

## Contribution Guidelines

Pull requests are welcome if the resource is directly useful for designers or developers working with color systems.

Good additions:

- Cultural color atlases with clear source or context.
- Design-token resources that export usable color data.
- Figma, CSS, Tailwind, DTCG, or accessibility-focused color workflows.
- Research references that help explain color meaning, perception, or provenance.

Please avoid:

- Generic SEO directories.
- Low-quality palette spam.
- Resources with unclear ownership or broken links.
- Purely decorative galleries without practical design or development value.
